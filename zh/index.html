VoxoB 使用指南 — 免费制作体素画

VoxoB 是一款完全在浏览器中运行的体素（立方体像素）编辑器。在电脑、平板或手机上就能制作 3D 像素画和体素模型。无需安装，无需登录。作品不会上传到外部，只保存在你正在使用的浏览器中。

三步制作体素画

  1. 做出形状：在右侧面板的“制作”标签中，一键自动生成房子、城堡、树木、地形等，或用左侧的画笔、矩形工具从零开始放置体素。
  2. 完善细节：点“✨ 下一步”添加地面、屋顶、窗户、阴影等，再用“风格转换”或“配色”统一整体颜色。
  3. 导出：从右上角的“导出”保存为 OBJ・STL・GLB・PNG 或视频，可直接用于 3D 打印、游戏素材或发到社交媒体。

快速上手

第一次打开页面时，可以选择“自动生成试试”“从空白画布开始”“从图片制作”三种方式。

在电脑上，从左侧选择工具（画笔、直线、矩形、圆、填充等），点击 3D 视图或 2D 截面即可放置。右键拖动旋转，Shift＋拖动平移，滚轮缩放。

在手机上，用底部栏或上方的“工具”“设置”打开面板。单指点按放置，双指旋转，捏合缩放。

把图片、文字和视频变成城市和生物（转换）

在右侧面板的“制作”标签中打开“转换”，选择图片或视频，或输入文字，选好风格后点“✨ 转换”。全部在浏览器中完成，不会上传任何内容。

城市：把图片当作地图，深色或鲜艳的部分长成高楼，绿色变成公园，蓝色变成水面；从正上方看，屋顶会拼出原图。生物：抠出轮廓并鼓起来，越宽的地方越厚。塔：像陶艺转盘一样把轮廓转成塔或花瓶。地形：把亮度变成高度。另外还有浮雕、平面，以及视频专用的“时间雕塑”——把运动的物体逐帧堆叠成立体轨迹。

打开“把转换过程保存为动画”后，搭建过程会保存为帧。“📱 短视频 (9:16)”可以录制竖屏视频：原素材 → 转换过程 → 绕成品转一圈。

请使用自己拍摄、绘制、书写的素材，或你有权使用的素材，避免使用他人的面孔和作品。

下一步与风格转换

点击上方的“✨ 下一步”（键盘为 N），会为当前作品添加一个合适的步骤：铺地面、加屋顶、开窗户、种树、加阴影、加深边角，只挑选适合当前形状的。每一步都可以用 Ctrl+Z 撤销。

右侧面板的“风格转换”可一次性把整个作品的颜色换成和风、复古、马卡龙、夜晚、秋天或黑白。“配色”中可以选择日本传统色、复古 16 色等调色板。

动画

添加帧即可制作逐帧动画。右侧面板的“生成动画”能把当前形状自动做成旋转、摆动、生长、溶解等 26 种动作。

用 FPS 调整播放速度，并导出为 WebM / MP4 视频。

从图片、视频和 3D 模型制作

读取 PNG / JPG / GIF / BMP 图片、MP4 / WebM / MOV 视频或 OBJ / STL 3D 模型，即可转换为体素。图片还能根据颜色生成深度，很适合把像素画变成立体。

导出与保存

可导出 OBJ（＋MTL）、STL（适合 3D 打印）、GLB（适合游戏引擎和 Web 3D）、PNG、WebM / MP4 视频以及 JSON。

作品会自动保存在浏览器中，也可以命名保存多个项目。“分享”会把作品打包进 URL 发送（不会保存到服务器）。

适用场景

  • 制作 3D 打印模型（导出 STL）
  • 为 Blender、Unity、Godot 等制作游戏素材和图标（OBJ / GLB）
  • 用方块搭建房屋、街景，以及和风神社、五重塔
  • 发到社交媒体的旋转动画和短视频（MP4 / WebM）
  • 在学校或家里学习 3D 与空间图形（无法安装软件的设备也能用）

常见问题

免费吗？
是的，完全免费，也不需要注册。
需要安装吗？
不需要。用 Chrome、Safari、Edge、Firefox 等浏览器打开页面即可使用。需要支持 WebGL 的设备。
数据保存在哪里？
只保存在你的浏览器中（localStorage）。清除浏览器数据后会丢失，重要的作品请导出为 JSON。
手机可以用吗？
可以。单指点按放置，双指旋转，捏合缩放。支持 iPhone、Android 和 iPad。
可以在 Blender 或 Unity 中使用吗？
可以。导出 OBJ（＋MTL）或 GLB 后，就能导入 Blender、Unity、Godot 等 3D 软件和游戏引擎。
可以 3D 打印吗？
可以。导出 STL，再用切片软件（Cura、PrusaSlicer 等）打开即可。
可以把图片转换成体素吗？
可以。读取 PNG / JPG / GIF / BMP 即可转换为体素，还能根据颜色生成深度。视频和 OBJ / STL 模型也能转换。
和 MagicaVoxel 有什么不同？
VoxoB 无需安装，在浏览器中就能运行，手机上也能用。一键自动生成和“下一步”让你不必逐个放置体素也能做出形状。
