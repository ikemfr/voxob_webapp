VoxoB の使い方 — 無料でボクセルアートを作る

VoxoB（ボクソブ）は、ブラウザだけで動くボクセル（立方体のドット）エディタです。3Dドット絵やボクセルアートを、PC・タブレット・スマホで作れます。インストールもログインも不要で、作ったデータは外部に送られず、使っているブラウザの中に保存されます。

ボクセルアートの作り方（3ステップ）

  1. 形を作る：右パネルの「作る」タブで、家・城・木・地形などをワンクリックで自動生成するか、左のペンや矩形ツールで一から置きます。
  2. 仕上げる：「✨ 次の一手」で地面・屋根・窓・陰影などを足し、「スタイル変換」や「配色」で全体の色を整えます。
  3. 書き出す：右上の「エクスポート」から OBJ・STL・GLB・PNG・動画で保存します。3Dプリントやゲーム素材、SNS 投稿にそのまま使えます。

はじめかた

ページを開くと、最初に「自動生成してみる」「まっさらから描く」「画像から作る」の3つが出ます。

PC は左のツール（ペン・直線・矩形・円・塗りつぶしなど）を選び、3D 画面か 2D 断面をクリックして置きます。右ドラッグで回転、Shift＋ドラッグで移動、ホイールでズーム。

スマホは下のバーや上の「ツール」「設定」でパネルを開き、1本指タップで置く、2本指で回転、ピンチでズームです。

次の一手とスタイル変換

上の「✨ 次の一手」（キーボードは N）を押すと、今の作品に合う次の工程をひとつ足します。地面を敷く・屋根を載せる・窓を付ける・木を植える・陰影をつける・角を締める、の中から形に合うものだけを選びます。どれも Ctrl+Z で取り消せます。

右パネルの「スタイル変換」は、作品全体の色を和風・レトロ・パステル・夜・秋・モノクロに一度で変えます。「配色」では和色やレトロ16色などのパレットを選べます。

アニメーション

フレームを追加してコマ送りで作れます。右パネルの「アニメ生成」は、今の形から回転・揺れ・成長・分解など26種類の動きを自動で作ります。

再生速度は FPS で調整し、WebM / MP4 の動画として書き出せます。

画像・動画・3Dモデルから作る

PNG / JPG / GIF / BMP の画像、MP4 / WebM / MOV の動画、OBJ / STL の3Dモデルを読み込むと、ボクセルに変換します。画像は色から奥行きを付けることもできます。ドット絵を立体にしたいときにも便利です。

書き出しと保存

OBJ（＋MTL）、STL（3Dプリンタ向け）、GLB（ゲームエンジン・Web 3D向け）、PNG、WebM / MP4 動画、JSON に書き出せます。

作品はブラウザに自動保存され、名前を付けて複数保存もできます。共有ボタンは作品を URL に詰めて渡せます（サーバーには保存しません）。

こんな用途に

  • 3Dプリント用のモデル作り（STL 書き出し）
  • Blender・Unity・Godot などに読み込むゲーム素材やアイコン（OBJ / GLB）
  • ブロックで組んだ建物や街並み、和風の神社・五重塔
  • SNS に載せる回転アニメや短い動画（MP4 / WebM）
  • 学校や家庭での 3D・空間図形の学習（インストールできない端末でも使えます）

よくある質問

無料ですか？
はい、無料です。登録も不要です。
インストールは必要ですか？
いいえ。ブラウザ（Chrome・Safari・Edge・Firefox など）でページを開くだけで使えます。WebGL が動く環境が必要です。
データはどこに保存されますか？
お使いのブラウザの中（localStorage）だけです。ブラウザのデータを消すと消えるので、大事な作品は JSON で書き出してください。
スマホでも使えますか？
はい。1本指タップで置く、2本指で回転・ピンチでズームです。iPhone・Android・iPad で動きます。
Blender や Unity で使えますか？
はい。OBJ（＋MTL）か GLB で書き出せば、Blender・Unity・Godot などの 3D ソフトやゲームエンジンに読み込めます。
3Dプリントできますか？
はい。STL で書き出して、スライサー（Cura・PrusaSlicer など）に読み込んでください。
画像をボクセルに変換できますか？
はい。PNG / JPG / GIF / BMP を読み込むとボクセルに変換し、色から奥行きを付けることもできます。動画や OBJ / STL モデルも変換できます。
MagicaVoxel などとの違いは？
VoxoB はインストールせずブラウザだけで動き、スマホでも使えます。ワンクリック自動生成や「次の一手」で、一から置かなくても形が作れるのが特徴です。
